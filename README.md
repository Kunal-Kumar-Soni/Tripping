## Tripping App

A modern, interactive **trip planning application** designed to help users organize activities, manage timelines, and visualize routes seamlessly — all with an intuitive drag-and-drop experience.

## Features

### Drag & Drop Planning

- Effortlessly move activities between the timeline and activity panel
- Smooth, responsive, and intuitive interactions

### Timeline Management

- Plan your day hour-by-hour with precision
- Automatic duration adjustments for activities

### Transport Integration

- Add transport between activities
- Calculate distance and improve route planning

### Google Maps Integration

- Visualize routes directly on the map
- Marker clustering for better performance
- Zoom-based rendering for optimized experience
